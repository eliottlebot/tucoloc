# Single hard-wired Flatshare

Tucoloc serves exactly one Flatshare (ours, three Flatmates), so the data has no notion of "which Flatshare" and there is no way to create a Flatshare, invite someone, or join one. Multi-flatshare support would cost a lot and buy nothing for three people. If another flatshare ever wants the app, it either deploys its own copy or we migrate the data to add a flatshare dimension.
